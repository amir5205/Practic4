# Интерактивная презентация: Анализ уязвимостей исходного кода и датасет CVE/CWE

Интерактивное веб-приложение для защиты практической работы №2 по дисциплине «Информационная безопасность» / «Анализ защищенности программного обеспечения».

Включает в себя:
- **16 интерактивных слайдов** с детальным разбором SAST и DAST инструментов (Bandit, Flawfinder, Cppcheck, ESLint, OWASP ZAP).
- **18 встроенных скриншотов** с результатами выполнения практических заданий и инспектором деталей.
- **Интерактивный датасет** с фильтрацией по CWE/CVE/OWASP Top 10, поиском и экспортом.
- **Режим докладчика (Speech Notes)** со шпаргалкой для устной защиты каждого слайда.
- **Экспорт в PowerPoint (.pptx)** одной кнопкой.

---

## 🚀 Быстрый старт (Локальный запуск)

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd cve-cwe-vulnerability-presentation
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:3000` (или `http://localhost:5173`).

4. Сборка для продакшена:
   ```bash
   npm run build
   ```

## 📦 Как выгрузить проект на GitHub

1. Инициализируйте локальный Git-репозиторий (если еще не инициализирован):

## ⚡ Развертывание (Деплой) на Vercel

### Способ 1: Через веб-интерфейс Vercel (Самый простой, рекомендуется)

1. Зайдите на [vercel.com](https://vercel.com) и войдите через свой аккаунт **GitHub**.
2. Нажмите кнопку **«Add New…»** ➔ **«Project»**.
3. В списке репозиториев найдите ваш репозиторий (например, `cve-cwe-presentation`) и нажмите **«Import»**.
4. Параметры сборки Vercel определит автоматически:
   - **Framework Preset**: `Vite`
   - **Build Command**: `vite build` (или `npm run build`)
   - **Output Directory**: `dist`
5. Нажмите **«Deploy»**.
6. Через 20–30 секунд ваш сайт будет опубликован и получит бесплатный HTTPS-домен вида `https://<проект>.vercel.app`!

---

### Способ 2: Через консоль (Vercel CLI)

1. Установите утилиту Vercel:
   ```bash
   npm install -g vercel
   ```
2. Выполните команду в папке проекта:
   ```bash
   vercel
   ```
3. Следуйте подсказкам в терминале для авторизации и подтверждения параметров сборки.
4. Для финального релиза:
   ```bash
   vercel --prod
   ```
